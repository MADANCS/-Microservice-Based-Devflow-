## 🌟 Featured Project

### 🚀 [DevFlow Platform](https://github.com/MADANCS/-Microservice-Based-Devflow-)
> **Next-Generation AI-Powered Developer Workflow & Project Management Platform**

- **Architecture**: 9 Spring Boot microservices (`api-gateway`, `auth-service`, `project-service`, `task-service`, `ai-engine`, `notification-service`, `analytics-service`, `integration-service`, `realtime-service`).
- **AI Engine**: Live AI daily standup update generator, dynamic sprint risk audit, and velocity-driven sprint optimizer.
- **Data Isolation**: User-isolated workspace persistence (`usr_<email_hash>`).
- **Frontend**: High-aesthetic React 19 client with real-time WebSocket activity streaming.
- 🔗 **Repo**: [https://github.com/MADANCS/-Microservice-Based-Devflow-.git](https://github.com/MADANCS/-Microservice-Based-Devflow-.git)
